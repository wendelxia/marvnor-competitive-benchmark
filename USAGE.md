# Start Using Marvnor

1. Register and sign in to the [customer portal](https://api.marvnor.com/).
2. Create an API key and save it; the full key is shown only once.
3. Choose your setup:
   - **VS Code or Codex:** open [Connect AI tools](https://api.marvnor.com/connect). See [setup and operating rules](docs/customer/llm-integration.md).
   - **Your own application:** follow the [API quickstart](USER_QUICKSTART.md). No SDK required.

## Guides

- [API reference](PUBLIC_EVALUATION_API.md): fields, six-field results, key lifecycle and errors.
- [Record management](docs/customer/record-management.md): corrections, selected deletion and batch imports.
- [Current plans and usage](https://api.marvnor.com/): account quota and subscriptions. Applications can read the [plan catalog](https://api.marvnor.com/v1/plans).
